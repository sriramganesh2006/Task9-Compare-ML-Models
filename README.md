**# Task 9: Compare Machine Learning Models**



**## Objective**

**Compare different supervised machine learning algorithms**

**for student result classification.**



**## Algorithms**

**1. Logistic Regression**

**2. Decision Tree Classifier**

**3. K-Nearest Neighbors (KNN)**



**## Technologies**

**- Python**

**- Pandas**

**- Matplotlib**

**- Scikit-learn**



**## Dataset**

**The dataset contains student age, marks, study hours,**

**attendance, and an illustrative Pass/Fail target.**



**## Methodology**

**1. Load and inspect the dataset.**

**2. Prepare input features and target labels.**

**3. Split the dataset into training and test sets.**

**4. Train three classification models.**

**5. Calculate accuracy, precision, recall, and F1-score.**

**6. Generate confusion matrices.**

**7. Compare the evaluation metrics.**

**8. Save the results and visualization.**



**## Run the Project**



**Install dependencies:**



&#x20;   **py -m pip install -r requirements.txt**



**Run:**



&#x20;   **py compare\_models.py**



**## Outputs**

**- Model comparison CSV**

**- Model comparison chart**

**- Comparison report**

**- Confusion matrices**



**## Conclusion**

**This project demonstrates how multiple machine learning**

**classification algorithms can be evaluated using the same**

**dataset and metrics.**



**The small sample dataset is for educational purposes only.**
